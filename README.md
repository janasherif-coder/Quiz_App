
# 🧠 C++ Quiz App

A simple interactive quiz application built using **C++**, where users can test their knowledge of Object-Oriented Programming (OOP) through multiple-choice questions.

---

### 🎯 About The Project

This project is a console-based quiz application that allows users to enter their names and answer a set of five OOP-related questions.

The application checks each answer, keeps track of the player's score, and displays the final results along with a personalized performance message.

---

### ✨ Features

- 👤 Enter the player's name.
- ❓ Answer 5 multiple-choice questions about OOP.
- ✅ Automatically check answers and provide instant feedback.
- 📊 Track the player's score.
- 📈 Calculate the final percentage.
- 🏆 Display a performance message based on the final score.
